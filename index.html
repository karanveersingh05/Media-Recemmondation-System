PROJECT 01 Content-Based Filtering

Movie Recommendation System

Finding the next film through metadata similarity.

This project explores content-based recommendation using a Hollywood movie dataset. Rather than relying solely on a film's popularity, it represents descriptive movie information as text and compares films according to the features they share.

A TF-IDF vectorizer transforms selected metadata, including genres, keywords, cast and crew information, into numerical representations. Cosine similarity then measures how closely the resulting feature vectors align. The notebook also uses difflib to help match a user's movie title to an available entry.

The result is a ranked set of similar movies based on their metadata, demonstrating how text processing and vector similarity can power a recommendation workflow.

PROJECT 02 Collaborative Item Similarity

Music Recommendation System

Using listening patterns to uncover related songs.

This project explores music discovery through user-song interaction data. The dataset combines listening records with song metadata, making it possible to examine both overall listening popularity and relationships between songs.

A popularity-based model ranks songs by their frequency in the listening records. A separate item-similarity model examines the sets of users associated with each song, then uses the Jaccard similarity index to quantify overlap between those sets.

The item-similarity workflow builds a co-occurrence-style similarity matrix and aggregates similarity scores to generate ranked recommendations. The core logic lives in a reusable Recommenders.py module, separate from the notebook used to load data and run experiments.
